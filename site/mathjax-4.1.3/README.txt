MathJax 4.1.3, self-hosted browser components from the npm package mathjax.
The companion font is @mathjax/mathjax-pagella-font 4.1.3, in ../@mathjax/.

Sources:
https://www.npmjs.com/package/mathjax/v/4.1.3
https://www.npmjs.com/package/@mathjax/mathjax-pagella-font/v/4.1.3

The nofont component omits the unused default font. The TeX boldsymbol
extension and English/Nemeth speech data are retained for the guides.
Speech JSON files are compacted without changing their data.
See LICENSE for MathJax code and the companion font directory for its
code and font licences.
