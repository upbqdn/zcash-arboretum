# NU7 source review — 23 September 2026

This is an editorial audit record, not another reader-facing guide. The
Arboretum targets the NU7 draft rather than teaching an obsolete parameter set
alongside it. Historical constants remain only where the activation-aware
halving calculation or verification of chain-history epochs requires them.

## Source inconsistencies not silently resolved in the guides

1. ZIP 218's subsidy formula divides the post-Blossom subsidy by another
   factor of three. With halving index 2, it gives 52,083,333 zatoshi. The
   accompanying note instead divides 156,250,000 by six; that is inconsistent
   with the formula. The guide derives the formula's result and distinguishes
   the following halving's 26,041,666-zatoshi subsidy.
2. ZIP 259's merged text removed the earlier draft's normative fee and
   reserve equations, but retains references to changes "specified below".
   ZIP 235 still requires a voluntary-removal field absent from ZIP 229's
   retained v6 format. A block-level replacement cannot be reconstructed from
   an obsolete PR diff and presented as the merged specification. The guide
   uses a symbolic removal amount in the reserve recurrence and identifies
   this missing integration rule.
3. ZIP 237 seeds the reserve from unclaimed historical subsidy and fees;
   its exact per-network amounts remain TODO. An earlier revision of PR 1363
   instead used an initially empty reserve. The merged ZIP 237, not that
   removed revision, governs the explanation.
4. ZIP 259 selects February 2031 for reissuance but assigns no height. Its
   provisional crossover calculation uses a different reserve quantity from
   ZIP 237's actual NSM value balance. It is not an assigned activation rule.
5. Merged ZIP 218 does not include Ironwood in its global action count;
   PR 1361 is the relevant open amendment. The guide must not silently apply
   an Orchard-only formula to both pools.
6. ZIP 218's 169.10 MB/day estimate counts compact payload fields and assumed
   headers, not the complete protobuf stream. For 330 Actions per block and
   3,456 blocks/day, the raw fields total 168,791,040 bytes/day; even before
   transaction/block metadata, the repeated Action messages total 181,336,320
   bytes/day. Trial-decryption counts also depend on the number of candidate
   viewing keys, not a universal multiplier of two.
7. ZIP 218's fee discussion conflates Sapling's sum-of-inputs-and-outputs
   resource count with ZIP 317's maximum-of-inputs-and-outputs fee count.
   The resource budget and conventional fee are distinct calculations.
8. ZIP 218's description of a current 99-block rollback window differs from
   the previously audited Zebra snapshot's 1,000-block window. Neither belongs
   in a NU7 parameter table: 600 is a proposed node-policy recommendation,
   not a consensus finality rule or a verified new implementation default.
9. ZIP 218 retimes halving progress but does not itself retime every fixed
   funding-stream endpoint. No unstated funding-stream amendment is assumed.
