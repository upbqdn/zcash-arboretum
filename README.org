#+TITLE: The Zcash Arboretum
#+AUTHOR: m@rek.onl
#+OPTIONS: toc:nil num:nil

Formal documentation of the [[https://z.cash/][Zcash]] protocol: the deployed Orchard and
Ironwood core and the protocols built on it. Claims are checked against the
protocol specification, the ZIPs and the deployed sources (librustzcash,
orchard, zebra, wallets).

The volumes are *non-normative*. The [[https://zips.z.cash/protocol/protocol.pdf][protocol specification]], the
[[https://zips.z.cash/][ZIPs]] and the consensus rules are authoritative; where this text disagrees
with them, this text is wrong.

Only what lies on the critical path is included, and it is explained in full.
Sprout, Sapling, the transparent layer and the legacy network stack appear
only where the surviving protocols depend on them.

* Volumes

Read each atop the volumes it names. Volume /name/ is =name-guide.tex=, its PDF
beside it.

** Foundations
1. *Math Guide*: groups, finite fields, elliptic curves, hardness assumptions.
2. *Crypto Guide*: provable security, hashes, commitments, PRFs, ciphers, key
   agreement, signatures, zero knowledge, SNARKs, Merkle trees.
3. *Halo 2 Guide*: the Orchard proof system, worked over a 97-element field;
   knowledge soundness; recursion, which Orchard does not deploy.

** Deployed protocol
4. *Consensus Guide*: Nakamoto consensus, confirmations, the most-work rule;
   NU7 timing, shielded-work limits, halvings, reserve accounting.
5. *Ironwood Guide*: an Orchard payment in the Ironwood pool, keys to proof;
   value conservation, double-spend resistance, spend authority, privacy.
6. *Wallet Guide*: key derivation, note discovery through a light-client
   server and what it learns, payment construction.

** Frontier
7. *FlyClient Guide*: Merkle mountain ranges, FlyClient sampling, the ZIP 221
   history commitment.
8. *ZSA Guide*: Zcash Shielded Assets; issuance, transfer, burn, security.
9. *FROST Guide*: threshold spend authorisation, re-randomised FROST (ZIP 312,
   ZIP 2005).

[[file:arboretum-complete.pdf][The Complete Arboretum]] joins all nine. The =parked/= directory holds research
snapshots outside the series (Voting, Tachyon, PQ, Crosslink), which the site,
the concordance and the complete edition omit; =talks/= holds slide decks.

* NU7

Pinned to 6 October 2026: Draft [[https://github.com/zcash/zips/blob/660b3f80bf48a354f69a950a14fb15b157a100c5/zips/zip-0259.md][ZIP 259]], which deploys 25-second blocks with
a shared shielded Action budget (ZIP 218), removal of 60% of fees from
circulation (ZIP 235), halving-preserving Network Sustainability Mechanism
reissuance (ZIP 237), no version 4 transactions (ZIP 2003; versions 5 and 6
unchanged) and funding streams adjusted to the new spacing (ZIP 207 Revision 2,
ZIP 214 Revision 3, ZIP 2008). It does not deploy ZIPs 233 or 234. Testnet
activates at height 4,465,026 and reissues from 7,305,222; the Mainnet
activation height, and with it the Mainnet reissuance height, is unassigned.
[[file:research/nu7-2026-09-23.md][The review of the previous pin]] lists its conflicts; this pin resolves all
but three in ZIP 218's rationale (its items 6–8).
